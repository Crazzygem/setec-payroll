## Findings

### HIGH (Hard Gate)

**1. (R-02) Em dashes in UI-facing strings.** 17 occurrences in text users see.
Evidence: payroll/views.py:45,90,99 (flash messages), employees/models.py:54
(`__str__` shown in delete modal), core/templates/core/index.html:19,28,34
(`default:'—'` placeholders) and :59 (card copy),
employees/templates/employees/list.html:137, payroll/templates/payroll/run_list.html:8,
payroll/templates/payroll/run_detail.html:102, payroll/templates/payroll/payslip.html:97,130,164,167.
Fix: replace with comma, colon, semicolon, parentheses, or the middle dot
already used in the app (for example `EMP001 · Dara Sok`).

**2. (R-02) Em dashes in project docs.** README.md (13, including H1),
DEMO.md (9), DESIGN.md:1 (H1, written by the agent minutes ago).
Fix: same replacements; DESIGN.md H1 becomes `# DESIGN.md: Payroll KH`.

**3. (R-02) Em dashes in code comments and docstrings.**
Evidence: payroll/rules.py:1,28, payroll/engine.py:1, payroll/views.py:123,
core/management/commands/seed_demo.py:53, payroll/tests/test_engine.py:1.
Fix: reword only; every one of these carries real information and the
information itself is kept (antislop-code scope guardrail).

**4. (R-03) No mobile layout.** The only `@media` in the whole project is
`@media print` (payslip.html:78). The 232px sidebar never collapses, there is
no hamburger, and row action buttons (`btn-sm py-0`) compute to roughly 24px
tall from CSS, under the 44px tap minimum.
Fix: small-screen breakpoint that collapses the sidebar (Bootstrap has the
offcanvas/nav components loaded) plus taller touch targets on coarse pointers.

**5. (R-32) Modals cannot be closed with Escape.** Modals are server-rendered
static divs (`modal fade show d-block`), no `keydown` listener exists anywhere,
and the Bootstrap JS bundle is loaded but not attached to these modals.
Close works only via the X link (Tab+Enter) or mouse.
Fix: one small vanilla listener in base.html: Escape presses the open modal's
close link (which already navigates back).

**6. (R-02) Em dashes in the archived build plan.**
`.hermes/plans/2026-09-25_222310-payroll-management-django.md` (~19 hits).
Recommendation: leave this file untouched. It is a historical session archive,
not shipped UI or docs. Owner decides.

### MEDIUM (Purpose-Gate)

**7. (R-01) Indigo accent contradicts the direction of record.** The build
still uses `#4F46E5` (base.html, login.html, payslip.html, .btn-accent)
while DESIGN.md sets emerald. The accent currently has no written purpose in
the direction, so it fails the purpose test.
Fix: swap to emerald. Contrast evidence: white on emerald-600 `#059669` is
3.77:1 (fails AA for normal text), so buttons and active nav must use
emerald-700 `#047857` (5.48:1 PASS); `#059669` stays for large text and soft
backgrounds. Existing indigo passes at 6.29:1, so this is a direction conflict,
not a contrast bug.

**8. (R-06) Typography contradicts DESIGN.md.** The build loads Sora +
Jakarta Sans; the direction of record is IBM Plex Sans (headings and body)
with tabular numerals for money columns.
Fix: swap the font link and the `font-family` rules; add
`font-feature-settings: "tnum" 1` to tables and money cells.

**9. (C-3, R-05 app-shell tell) Dashboard link cards duplicate the sidebar.**
core/templates/core/index.html:48-70: two cards whose only content is "Open
Employees" / "Open Payroll Runs", links the sidebar already carries. They add
no information and make the dashboard read as filler.
Fix options: (a) remove the two cards, keeping the stat row; (b) replace with
a short recent-runs list (real data from PayrollRun).
